# Задание: Отзыв о Хогвартсе

> **Task ID:** `react-feedback-01`
## Суть задания

Ты создашь **форму обратной связи** в стиле Хогвартса на React. Студент ставит оценку звёздами, пишет отзыв об обучении и указывает свой Gmail. После отправки красиво оформленное сообщение автоматически улетает в **Telegram-бот**.

Это задание про управляемые формы, валидацию и работу с внешним API через `fetch`.

---

## 📋 Пошаговый план

### 1️⃣ Создай проект и структуру

Создай React-приложение. Структура компонентов:

```
src/
├── components/
│   ├── StarRating.jsx
│   ├── FeedbackForm.jsx
│   └── SuccessMessage.jsx
└── App.jsx
```

---

### 2️⃣ Сделай управляемую форму

В `FeedbackForm.jsx` создай три поля. Каждое поле — отдельный `useState`:

| Поле | Тип | Состояние |
|------|-----|-----------|
| Оценка | Звёзды (1–5) | `rating` |
| Отзыв | Textarea | `review` |
| Gmail | Email input | `email` |

Все поля — **управляемые**: значение берётся из состояния, изменение обновляет состояние через `onChange`. Никаких `ref` и `document.getElementById`.

---

### 3️⃣ Создай компонент звёздного рейтинга

В `StarRating.jsx` отрисуй 5 звёзд. Логика:

- Звезда закрашена если её номер ≤ текущему рейтингу
- Клик на звезду — устанавливает рейтинг
- Наведение мыши — подсвечивает звёзды до курсора (используй отдельный `useState` для hover)

Компонент принимает `value` и `onChange` как пропсы — родитель управляет значением.

---

### 4️⃣ Добавь валидацию перед отправкой

Перед отправкой проверь каждое поле:

| Поле | Условие |
|------|---------|
| Оценка | Выбрана хотя бы 1 звезда |
| Отзыв | Минимум 10 символов |
| Gmail | Содержит `@gmail.com` |

Если что-то не заполнено — покажи текст ошибки рядом с полем. Кнопка отправки остаётся активной, но ошибки появляются при попытке отправить.

---

### 5️⃣ Подключи Telegram-бот

Создай бота через **@BotFather** в Telegram — получишь токен. Узнай свой `chat_id` через **@userinfobot**.

При отправке формы сделай `fetch` запрос к Telegram Bot API:

```
https://api.telegram.org/bot<TOKEN>/sendMessage
```

Метод POST, тело запроса — JSON с полями `chat_id` и `text`.

> ⚠️ Токен бота храни в файле `.env` как `REACT_APP_BOT_TOKEN`. Никогда не вставляй токен прямо в код — это публичный репозиторий.

---

### 6️⃣ Оформь сообщение в Telegram

Сообщение которое приходит в бот должно быть читаемым. Собери текст из данных формы:

| Элемент | Пример |
|---------|--------|
| Заголовок | `📋 Новый отзыв о Хогвартсе` |
| Оценка | `⭐⭐⭐⭐☆ (4 из 5)` |
| Автор | Gmail студента |
| Отзыв | Текст отзыва |
| Дата | Текущая дата и время |

Telegram поддерживает разметку — используй `parse_mode: "HTML"` и теги `<b>`, `<i>` чтобы выделить важные части.

---

### 7️⃣ Покажи экран успеха

После успешной отправки скрой форму и покажи `SuccessMessage.jsx` — красивое сообщение в стиле Хогвартса: например, летящее письмо-сова с текстом _"Твой отзыв доставлен в Хогвартс!"_

Кнопка "Отправить ещё один отзыв" сбрасывает все поля и возвращает форму.
