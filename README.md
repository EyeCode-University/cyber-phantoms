## Суть задания

Создай систему **рандомного бокса и инвентаря** как в играх (CS2, Dota 2, Valorant). Пользователь открывает кейсы, получает предметы, может просматривать их, продавать за деньги или удалять. Всё управление через **React Context**.

---

## Выбери игру

| Игра | Предметы |
|------|----------|
| 🔫 **CS2** | Скины оружия, ножи, перчатки |
| ⚔️ **Dota 2** | Скины героев, курьеры, арканы |
| 🎯 **Valorant** | Скины оружия, ножи, банеры |
| 🎮 **Fortnite** | Скины персонажей, кирки, эмоции |

---

## 📋 Что должно быть

### 1️⃣ Система боксов

**Открытие бокса:**
- Кнопка "Открыть кейс"
- Анимация открытия
- Случайный предмет с учётом редкости

**Редкость предметов:**
```
Common (серый)    → 50% шанс → цена 10-50₽
Rare (синий)      → 30% шанс → цена 50-200₽
Epic (фиолетовый) → 15% шанс → цена 200-500₽
Legendary (золотой) → 5% шанс → цена 500-2000₽
```

---

### 2️⃣ Инвентарь

| Функция | Описание |
|---------|----------|
| **Просмотр** | Сетка всех полученных предметов |
| **Клик на предмет** | Открывается модалка с деталями |
| **Продажа** | Кнопка "Продать" → деньги на баланс |
| **Удаление** | Кнопка "Удалить" → предмет исчезает |

---

### 3️⃣ Модальное окно

При клике на предмет показывай:
- Большое изображение предмета
- Название и описание
- Редкость (цвет + текст)
- Цена продажи
- Кнопки: "Продать", "Удалить", "Закрыть"

---

### 4️⃣ Баланс пользователя

```
┌─────────────────────┐
│ 💰 Баланс: 1,250₽  │
│ 📦 Предметов: 12    │
└─────────────────────┘
```

- Начальный баланс: **500₽**
- Стоимость открытия бокса: **100₽**
- При продаже → деньги добавляются к балансу
