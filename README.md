🐦 Тема: Компоненты, props, рендеринг списков, структура интерфейса

Example: Название задания: Chess Board UI ♔ ♕ ♖ ♗ ♘ ♙

Необходимо создать мини-игру “Шахматы”, но без полноценной логики шахмат. Основная цель задания — построить шахматную доску при помощи React компонентов.

Приложение должно отображать шахматную доску 8x8, где каждая клетка является отдельным React-компонентом.

Основные требования:

Создать компонент Board, который отвечает за всю шахматную доску.

Создать компонент Cell, который отвечает за одну клетку доски.

Компонент Board должен программно генерировать 64 клетки.

Цвета клеток должны чередоваться как в настоящих шахматах:

белая
черная
белая
черная

и так далее.

При клике на клетку она должна подсвечиваться.

Можно дополнительно добавить:

отображение координат (A–H, 1–8)
отображение выбранной клетки
легкую анимацию при выборе клетки

Важно:
Шахматные фигуры реализовывать необязательно.
Главная цель — компонентная архитектура и правильная генерация доски.
