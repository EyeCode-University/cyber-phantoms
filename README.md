# 🧠 Задание: Навигация Desktop + Mobile в Next.js

Создай в Next.js проекте навигацию, которая по‑разному выглядит на десктопе и на мобиле, но использует один и тот же набор ссылок и корректно подсвечивает активный маршрут.

---

## Стэк и формат

Проект на Next.js + React.  
Роутинг — встроенный (App Router или Pages Router).  
Оформление — любыми удобными тебе стилями (CSS‑модули, Tailwind, styled‑components и т.п.).[web:61][web:64][web:68]

---

## Суть задачи

У приложения есть несколько страниц, например:

```text
/            — главная
/about       — о проекте
/services    — услуги
/contacts    — контакты
```

Нужно реализовать две разные навигации:

### DesktopNav

Компонент для широких экранов.  
Отображается только на десктопной ширине (ориентир — от 1024px и выше).  
Содержит горизонтальное меню со ссылками.  
Активный маршрут визуально выделяется (цвет, фон, подчёркивание и т.д.).  
Текущий путь определяется через `usePathname` из `next/navigation` или аналогичную логику.[web:66][web:67][web:69][web:70]

### MobileNav

Компонент для узких экранов.  
Показывается только на мобильной ширине.  
Верхняя панель с иконкой «бургер».  
По нажатию на бургер появляется/исчезает мобильное меню с теми же ссылками, что и в DesktopNav.[web:61][web:62][web:63]  
Активный маршрут также подсвечивается, а после клика по пункту меню панель закрывается.

---

## Поведение вёрстки

На большом экране виден только DesktopNav.  
На маленьком — только MobileNav.  
Переключение можно решить чисто через CSS‑медиа‑запросы или через условный рендер по ширине окна — на твоё усмотрение. Важно, чтобы в любой момент у пользователя была ровно одна навигация, а не две одновременно.

---

## Итог задания

В корне проекта должен быть рабочий Next.js‑приложение с:

```text
components/DesktopNav.(tsx|jsx)
components/MobileNav.(tsx|jsx)
```

и несколькими страницами для проверки роутинга.  
Активная ссылка в обоих вариантах меню всегда соответствует текущему адресу.  
К проекту приложи README с командами установки и запуска (`npm install`, `npm run dev` и т.п.).
